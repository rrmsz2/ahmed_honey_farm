# 🍯 تطبيق مزرعة أحمد للعسل

## 📖 نظرة عامة
تطبيق متكامل لإدارة وبيع منتجات العسل، يحتوي على:
- 🛒 واجهة المستخدم للتصفح والشراء
- 👨‍💼 لوحة تحكم الإدارة
- 💳 نظام السلة والطلبات
- 📱 تصميم متجاوب

## 🐳 التشغيل باستخدام Docker (موصى به)

**للبدء السريع:**
```bash
chmod +x build-and-run.sh
./build-and-run.sh
```

**أو اقرأ:**
- [QUICK_START.md](QUICK_START.md) - دليل البدء السريع
- [DOCKER_README.md](DOCKER_README.md) - الدليل الكامل

## 🌐 الوصول للتطبيق
- المحلي: http://localhost:3003
- الإنتاج: http://hony.fidanet.om

## 👤 معلومات Admin الافتراضية

## 🛠️ التقنيات المستخدمة
- **Frontend:** React 19 + Tailwind CSS
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Deployment:** Docker

## 📝 الميزات
✅ واجهة مستخدم حديثة وسريعة الاستجابة
✅ لوحة تحكم إدارية متكاملة
✅ إدارة المنتجات والطلبات
✅ نظام سلة المشتريات
✅ دعم اللغة العربية

## 🔒 الأمان
- تشفير كلمات المرور
- JWT للمصادقة
- CORS محمي
- Nginx reverse proxy
